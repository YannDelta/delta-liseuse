# Transfert des planches

Lire `TRANSFERT-PLANCHES.md` avant un transfert d'images.

- Dépôt : `YannDelta/delta-liseuse`, branche `main`.
- Une planche courante = un véritable fichier JPEG `images/Pxx-selection.jpg`.
- Pour ajouter ou remplacer une planche, modifier uniquement ce JPEG. Ne pas modifier le récit, les annotations ou les anciennes versions.
- Ne pas intégrer les images dans `assets.js` ou `data.js` et ne pas changer `hasImage` : la liseuse détecte les fichiers.
- Ne jamais remplacer une image par du texte Base64 ou un fichier blanc.
- Conserver les autres modifications présentes sur `main` ; jamais de push forcé.
- Vérifier le fichier publié et l'affichage, pas seulement la création d'un commit.
