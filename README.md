# Delta des mondes — liseuse

Liseuse de travail de l’épisode 1.

- `index.html` : interface de lecture
- `data.js` : récit, découpage, annotations et métadonnées
- `images/Pxx-selection.jpg` : planches courantes, détectées automatiquement
- `assets.js` : ressources intégrées et anciennes versions
- `current-images.js` : détection et actualisation des planches courantes

La structure sépare volontairement le texte des images afin que les corrections de récit puissent être publiées sans reconstruire toute la liseuse.

Pour ajouter ou remplacer une planche depuis ChatGPT, suivre [TRANSFERT-PLANCHES.md](TRANSFERT-PLANCHES.md). Il suffit de déposer le JPEG sous son nom fixe, puis d'utiliser **Actualiser les planches** dans la liseuse.
